# portfolio

A static portfolio site. 
- `index.html` + `content.js` — the main site. All content lives in `content.js`.

## Edit

Edit on `content.js`. Change the text in `site`, `hero`, `about`, `skills`, `projects`, `contact`, and `footer`. 

- Add a project, skill group, or nav link: copy a whole block.
- Hide a nav link: delete its line.
- Keep nav `href="#about"` in sync with each section's `id="about"`.

## View locally

Double-click `index.html`, or use VS Code's Live Server extension.

## Deploy

1. Push the repo to GitHub.
2. **Settings → Pages → Deploy from a branch → `main` / root → Save**.
3. Site goes live at `https://<username>.github.io/<repo>/` (or `https://<username>.github.io` if the repo is named `<username>.github.io`).
